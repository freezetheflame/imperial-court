# 前端设计指令（Design Brief）— 沉浸式宫廷风格改造

> 把 frontend/ 从朴素骨架改造成"皇帝临朝"的沉浸式宫廷界面。
> 功能已全部可用，本任务只做视觉与交互升级，不改功能逻辑。

## 项目背景

Imperial Court（朝堂）是一个"制度是一等公民"的多 agent 编排系统。用户扮演皇帝：下达上谕（任务）、审批奏折（汇报）、裁决弹劾（御史台）、查看官职墙（岗位）。后端 API 契约见 `docs/api-contract.md`，当前前端骨架在 `frontend/src/`，功能完整（列表/表单/批红/裁决/任命 + SSE 实时刷新）。

## 设计目标

模拟古代朝堂的视觉与交互体验——让皇帝（用户）感觉自己在批阅奏折、朱批御览，而不是在用普通的管理后台。**沉浸感优先，但保持可用性**：信息密度、点击路径不能因为"古风"而变差。

## 视觉规范

### 配色（用 Tailwind v4 @theme token）
- 朱红 `#8b1a1a`（已定义为 `--color-imperial-vermillion`）：主色，用于标题、按钮、朱批、强调
- 宣纸底 `#fdf8f0`（已定义为 `--color-imperial-parchment`）：全局背景
- 墨色 `#2b2b2b`：正文
- 金色 `#a67c00`（已定义为 `--color-imperial-gold`）：点缀、官职等级、警告
- 深宫墙色（可自定义一个深红棕 `#4a1a1a` 之类）：侧栏/顶栏背景

### 字体
- 中文衬线：`"Noto Serif SC", "Songti SC", "STSong", serif`（index.css 已设置）
- 标题可加大字号、字距，营造"诏书"感
- 朱批文字可稍大、更醒目（像皇帝朱砂笔迹，可用楷体感：`"Kaiti SC", "KaiTi", serif`）
- 不引外部字体（离线可用，系统字体栈优先）

### 元素风格
- **奏折卡片**：宣纸底色 + 浅色边框/暗纹，像一折奏章；正文横排即可（可加首行缩进/引号）；右上角标注呈报者官职（如"丞相谨奏"）；未读/急件有朱红标记
- **朱批**：皇帝批语用朱红色、楷体感、比正文醒目，旁边可配一个印章感元素（如红色方框内"御览之宝"字样，纯 CSS 实现）
- **上谕表单**：做成"拟旨"面板——卷轴式标题区、印章装饰、正式诏书用语预览（提交后显示"奉天承运皇帝，诏曰…"）
- **官职墙**：像官员告示/牙牌——每岗位一张"名牌"，在职（朱红边）、空缺（金色/虚线边）、革职（灰色）
- **侧栏**：可保留左侧导航但升级（深宫墙色背景、米色文字、当前项朱红高亮），或改成顶部横栏（宫灯式分隔）——二选一，保持简洁

### 微交互
- 批红/裁决/任命按钮：悬停有轻微变化（变深/下划线），点击有反馈
- SSE 新奏折到达时，列表可有一瞬的"新到"高亮（淡入动画）
- 空状态文案用古风口吻（如"暂无奏折，静候臣工呈报"）

## 技术约束（必须遵守）

1. **Tailwind CSS v4**（@tailwindcss/vite 插件，无 tailwind.config.js，用 CSS 里的 `@theme` 定义 token）——已有的 token 在 `frontend/src/index.css`
2. **React 19 + TypeScript**，`verbatimModuleSyntax` 已开启 → 类型导入必须 `import type { X }`
3. **不改后端、不改 `frontend/src/lib/api.ts` 的接口**（数据形状见 api-contract.md）
4. **保留 SSE 实时刷新**（`useEventStream` 已接好，不要动）
5. **保留 react-router 路由结构**（四页面 + Layout）
6. 样式可以写在组件内联 style、CSS 类或 Tailwind 工具类里，风格统一即可；如果引入新的 CSS 文件，记得在 `main.tsx` 或 `index.css` 挂载
7. **不要添加新的 npm 依赖**（除非绝对必要；图标用 unicode/CSS 实现，避免装 icon 库）
8. 完成后必须运行 `npm run build`（tsc -b && vite build），确保类型检查与构建通过

| `src/pages/MemorialsPage.tsx` | 白卡片列表 | 奏折卡片化，批红按钮→朱批样式，批语显示朱批效果 |
| `src/pages/EdictsPage.tsx` | 普通表单 | 拟旨面板，提交后展示正式诏书文本，古风排版 |
| `src/pages/CensoratePage.tsx` | 统计卡+案件列表 | 御史台案卷风格，裁决按钮朱批化 |
| `src/pages/PostsPage.tsx` | 网格名片 | 官职名牌风格（在职/空缺/革职三态分明） |
| `src/index.css` | 基础主题 | 可补充 token（深宫墙色等）、通用动效、古风细节 |

## 验收标准

1. `npm run build` 通过（tsc 无错、vite 构建成功）
2. 四个页面视觉风格统一、有宫廷沉浸感
3. 功能不变：上谕可下达、奏折可批红、弹劾可裁决、空缺可任命、SSE 实时刷新正常
4. 响应式可用（窄屏不崩，卡片换行即可）
5. 代码风格干净：无未使用 import、无 any 滥用、类型正确
